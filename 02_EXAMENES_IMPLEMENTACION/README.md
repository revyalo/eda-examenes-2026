# Exámenes de implementación

Contiene tres proyectos Maven independientes:

- `examen_impl_2026_01`: árboles binarios.
- `examen_impl_2026_02`: mapa hash con direccionamiento abierto.

Cada proyecto incluye README, código esqueleto, tests públicos, tests avanzados y guía de corrección.
