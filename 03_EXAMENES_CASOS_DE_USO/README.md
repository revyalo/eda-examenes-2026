# Exámenes de casos de uso

Contiene tres proyectos Maven independientes:

- `examen_cu_2026_01`: plan de evacuación con grafos ponderados.
- `examen_cu_2026_02`: organigrama con árboles generales.
- `examen_cu_2026_03`: archivo de incidencias con mapas y diccionarios.

El alumno debe usar las estructuras entregadas, no reimplementarlas desde cero.
