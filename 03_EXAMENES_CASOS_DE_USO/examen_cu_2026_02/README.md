# Examen caso de uso 2026 02: organigrama de servicios

Tipo: caso de uso

## Enunciado

El ayuntamiento organiza sus empleados en un árbol general. Complete `OrganigramaServicios` para insertar empleados bajo un jefe, consultar subordinados directos, obtener la ruta de mando hasta la raíz y listar todo el equipo de un responsable.

## Entrega

No se pueden modificar las cabeceras públicas entregadas. Se permite añadir métodos privados y atributos privados cuando sea necesario. No se deben sustituir las estructuras del entorno por colecciones de `java.util` salvo en usos auxiliares similares a los vistos en clase.

## Tests

Tests públicos: `src/test/java/*PublicTest.java`.

Tests avanzados: `src/test/java/*AdvancedTest.java`.

Para ejecutar:

```bash
mvn test
```

El esqueleto inicial debe compilar. Es normal que los tests fallen hasta completar los `TODO`.
