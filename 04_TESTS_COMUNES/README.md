# Tests comunes

Esta carpeta documenta utilidades recurrentes usadas en los tests:

- Convertir `Iterable` a colección para comparar contenido.
- Probar casos vacíos, un elemento y varios elementos.
- Separar tests públicos de tests avanzados.

Las utilidades se han dejado documentadas aquí para no introducir dependencias cruzadas entre proyectos de examen.
