# Entrenamiento intensivo: nuevos ejercicios de examen EDA

Esta carpeta contiene ejercicios nuevos basados en el estilo de los exámenes analizados.

## Organización

- `00_GUIA_REPASO`: guía general en Markdown y PDF.
- `01_IMPLEMENTACION_PURA`: ejercicios de grafos, árboles, iteradores, ABB/AVL y diccionarios ordenados. Cada ejercicio grande tiene su propio proyecto `esqueleto/`.
- `02_CASOS_DE_USO`: casos de uso con `HashMap`, `HashSet`, `TreeMap`, `TreeSet` y `PriorityQueue`. Cada caso tiene su propio proyecto `esqueleto/`.
- `03_EXAMENES_PROPUESTOS`: combinaciones tipo examen, ahora tambien con proyecto `esqueleto/` y tests.
- `04_INDICES`: índices generales y resultados de verificación.
- `06_RUTA_RECOMENDADA`: ruta de menos a más con esqueletos y tests para empezar por lo esencial.

## Cómo usarlo

1. Lee el README del ejercicio.
2. Entra en la carpeta `esqueleto/` de ese ejercicio.
3. Completa el método/clase indicada.
4. Ejecuta `mvn test` desde esa carpeta.

No hay soluciones incluidas.

## Estado de los esqueletos individuales

- Implementación pura: 70 proyectos individuales.
- Casos de uso: 15 proyectos individuales.
- Exámenes propuestos: 4 proyectos de simulacro.
- Total: 89 proyectos Maven.
