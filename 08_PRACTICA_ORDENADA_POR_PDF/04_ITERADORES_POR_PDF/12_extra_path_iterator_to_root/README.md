# PathIteratorToRoot

        **Origen:** Ejercicio nuevo de práctica: iterador de camino desde un nodo hasta la raíz.

        **Dificultad:** Muy alta

        ## Enunciado

        Implementa un iterador que empiece en una posición objetivo y vaya subiendo por parent hasta la raíz.
Debe devolver primero el nodo inicial y terminar en la raíz.

        ## Qué debes tocar

        Completa la clase:

        `src/main/java/es/urjc/grafo/EDA/examen/iteradores/PathIteratorToRoot.java`

        No cambies la firma pública de constructores ni métodos. Puedes añadir atributos privados o métodos
        auxiliares si los necesitas.

        ## Tests

        Ejecuta:

        ```bash
        mvn test
        ```

        Los tests están en `src/test/java/es/urjc/grafo/EDA/examen/iteradores/PathIteratorToRootTest.java`.
        Deben fallar inicialmente por los TODO esperados.
