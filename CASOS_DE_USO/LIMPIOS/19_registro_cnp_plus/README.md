# RegistroCNPPlus

Simulacro de casos de uso basado en oposiciones CNP.

Debes elegir las estructuras privadas para buscar por DNI, consultar rangos de nota media y devolver rankings. El esqueleto no trae mapas ni arboles ya creados: declaralos tu.

Ejecuta `mvn test`. Los tests fallan hasta completar los TODOs.
