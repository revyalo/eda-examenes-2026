# Casos De Uso

Ejercicios para practicar modelado con estructuras permitidas: `HashMap`, `HashSet`, `TreeMap`, `TreeSet`, `PriorityQueue` y grafos manuales con mapas de adyacencia cuando proceda.

## Carpetas

- `LIMPIOS`: recomendada para empezar. Tienen dominio completo y gestor vacio para que tu declares las estructuras.
- `DESDE_PDFS`: casos reconstruidos desde examenes reales. Mantienen dominio, cabeceras y tests.
