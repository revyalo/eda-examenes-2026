# Casos De Uso

Ejercicios para practicar modelado con estructuras permitidas: `HashMap`, `HashSet`, `TreeMap`, `TreeSet`, `PriorityQueue` y grafos manuales con mapas de adyacencia cuando proceda.

## Carpetas

- `LIMPIOS`: recomendada para empezar. Tienen dominio completo y gestor vacío para que tú declares las estructuras.
- `DESDE_PDFS`: casos reconstruidos desde exámenes reales.

9. `DESDE_PDFS/03_cni_interacciones`
10. `DESDE_PDFS/13_red_p2p_septiembre_2024`

## Cómo usar

Entra en un proyecto y ejecuta:

```bash
mvn test
```

Los tests están completos. El gestor/servicio está incompleto a propósito.
