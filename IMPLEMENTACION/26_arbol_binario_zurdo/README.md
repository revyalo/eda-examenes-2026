# Arbol binario zurdo

Ejercicio inspirado en la ampliacion de `LinkedBinaryTree` donde se pide `isOdd`.

Un arbol binario es zurdo si:

- esta vacio,
- solo tiene raiz,
- o mas de la mitad de sus descendientes estan en el hijo izquierdo.

Debes completar `MoreFunctionality.isOdd(BinaryTree<E> tree)` sin modificar la cabecera.

```bash
mvn test
```
