# LevelsComplete

Ejercicio inspirado en el examen de enero de 2018.

Completa `LevelsComplete.levelsComplete`, que recibe un arbol binario y devuelve una coleccion iterable con los niveles completos.

Se considera que:

- la raiz esta en el nivel `1`,
- un nivel esta completo si todos los nodos internos de ese nivel tienen dos hijos,
- las hojas no rompen la completitud de su nivel.

mvn test
