# Parcial1: antecesors y degree

Ejercicios de arboles generales.

Completa la clase `Parcial1`.

- `antecesors(tree, node)`: devuelve la lista de ancestros de `node`, empezando por su padre y terminando en la raiz.
- `degree(tree)`: devuelve el grado del arbol, entendido como el maximo numero de hijos de cualquier nodo.

Puedes anadir metodos privados, pero no modificar las cabeceras publicas.

```bash
mvn test
```
