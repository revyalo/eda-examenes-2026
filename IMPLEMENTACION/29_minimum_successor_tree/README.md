# MinimumSuccessorTree y MaximumPredecessorTree

Ejercicio de arbol binario de busqueda inspirado en el enunciado de las capturas.

Debes completar:

- `MinimumSuccessorTree.minimum(Position<E> pos)`,
- `MinimumSuccessorTree.minimum()`,
- `MinimumSuccessorTree.iterator()`,
- `InorderMinimumSuccessorTreeIterator`,
- `MaximumPredecessorTree.maximum(Position<E> pos)`,
- `MaximumPredecessorTree.maximum()`.

El arbol `MinimumSuccessorTree` ordena como un ABB normal. El arbol `MaximumPredecessorTree` ordena al reves: el hijo izquierdo almacena valores mayores y el derecho valores menores.

No modifiques las cabeceras publicas.

```bash
mvn test
```
