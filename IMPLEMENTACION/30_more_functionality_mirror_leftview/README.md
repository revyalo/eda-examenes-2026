# MoreFunctionality: checkMirror y leftView

Ejercicio de arboles inspirado en las capturas.

Completa:

- `checkMirror(t1, t2)`: determina si dos arboles binarios son reflejo uno del otro, comparando estructura y elementos.
- `leftView(tree)`: devuelve los elementos que se verian desde el lado izquierdo de un arbol n-ario, un elemento por nivel.

```bash
mvn test
```
