# Implementación

Ejercicios de implementación pura. Aquí debes completar métodos internos de estructuras o algoritmos sobre las estructuras del entorno de la asignatura.

## Orden recomendado

1. `01_enero_2026_grafos_arboles_iterador`
2. `02_diciembre_2025_complementario_grado_identicos`
3. `03_diciembre_2025_euler_descendants_symmetric`
4. `05_arboles_perfecto_iterador`
5. `04_hipergrafo`
6. `06_junio_2025_iteradores_red_electrica_parte_impl`
7. `07_septiembre_2024_bst_remove_half_nodes_parte_impl`
8. `08_practica_extra_10_ejercicios`
9. `11_grafos_ciclo_mas_corto`
10. `12_grafos_vertices_criticos_basico`
11. `16_arbol_binario_frontera`
12. `19_arbol_general_podar_subarboles`
13. `23_arbol_general_diametro`

El proyecto `08_practica_extra_10_ejercicios` contiene 10 ejercicios nuevos de grafos y arboles, de dificultad similar o superior al examen de implementacion.

Los proyectos `11`, `12`, `16`, `19` y `23` vienen del simulacro nuevo: son ejercicios sueltos de dificultad alta/muy alta para practicar recorridos adaptados.

## Cómo usar

Entra en un proyecto y ejecuta:

```bash
mvn test
```

No cambies firmas públicas. Completa solo los TODO del ejercicio.
