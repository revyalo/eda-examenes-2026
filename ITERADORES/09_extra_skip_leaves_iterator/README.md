# SkipLeavesIterator

        **Origen:** Ejercicio nuevo de práctica: recorrer solo nodos internos de árbol general.

        **Dificultad:** Media-alta

        ## Enunciado

        Implementa un iterador sobre árbol general que salte las hojas y devuelva únicamente nodos internos.
El orden esperado es por niveles.

        ## Qué debes tocar

        Completa la clase:

        `src/main/java/es/urjc/grafo/EDA/examen/iteradores/SkipLeavesIterator.java`

        No cambies la firma pública de constructores ni métodos. Puedes añadir atributos privados o métodos
        auxiliares si los necesitas.

        ## Tests

        Ejecuta:

        ```bash
        mvn test
        ```

        Los tests están en `src/test/java/es/urjc/grafo/EDA/examen/iteradores/SkipLeavesIteratorTest.java`.
        Deben fallar inicialmente por los TODO esperados.
