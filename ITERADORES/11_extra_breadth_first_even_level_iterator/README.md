# BreadthFirstEvenLevelIterator

        **Origen:** Ejercicio nuevo de práctica: BFS filtrando niveles pares.

        **Dificultad:** Alta

        ## Enunciado

        Implementa un iterador por anchura que devuelva únicamente posiciones situadas en niveles pares:
0, 2, 4, etc.

        ## Qué debes tocar

        Completa la clase:

        `src/main/java/es/urjc/grafo/EDA/examen/iteradores/BreadthFirstEvenLevelIterator.java`

        No cambies la firma pública de constructores ni métodos. Puedes añadir atributos privados o métodos
        auxiliares si los necesitas.

        ## Tests

        Ejecuta:

        ```bash
        mvn test
        ```

        Los tests están en `src/test/java/es/urjc/grafo/EDA/examen/iteradores/BreadthFirstEvenLevelIteratorTest.java`.
        Deben fallar inicialmente por los TODO esperados.
