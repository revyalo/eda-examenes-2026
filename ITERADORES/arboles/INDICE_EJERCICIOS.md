# Iteradores - Arboles generales

Iteradores sobre arboles generales.

## Como usarlo

Abre este directorio como proyecto Maven o entra por terminal y ejecuta:

```bash
mvn test
```

Los metodos del alumno se mantienen como esqueletos. Es normal que `mvn test` falle hasta que completes los TODOs; para comprobar solo compilacion usa `mvn test -DskipTests`.
